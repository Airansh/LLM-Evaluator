# EvalForge frontend

Next.js (App Router) + TypeScript + Tailwind + Recharts. All data comes from the EvalForge backend's public API; provider API keys never reach the browser.

```bash
npm install
cp .env.example .env.local   # optional; defaults to http://localhost:8000
npm run dev                  # http://localhost:3000
npm run lint && npx tsc --noEmit && npm run build
```

| Route | Screen |
| --- | --- |
| `/` | Dashboard: recent experiments, run status, case-evaluation count, regression indicators |
| `/experiments/new` | Create: name, prompt, sample or uploaded JSON dataset (validated by the backend), models with key availability, compatible baselines, threshold. `?baseline=<id>` pre-fills a candidate from an existing experiment |
| `/experiments/[id]` | Results: model table with denominators, regression panel, quality-vs-cost chart, per-case grid; polls while running |
| `/experiments/[id]/test/[testId]` | Failure inspector: question, context, expected answer, every model's response, metrics, judge rationale, costs and errors |

`AGENTS.md` / `CLAUDE.md` are generated by Next.js and point coding agents to the version-matched docs in `node_modules/next/dist/docs/`.
